# Seismic Monitoring for Traffic and Environmental Management in Greater Manchester

## MSc Data Science Dissertation

Author: Abdinassir Mohamed Hared

Supervisor: Dr Rochelle Taylor

Manchester Metropolitan University

## Project Overview

This repository contains the complete notebook used to produce the analyses, models, figures and results reported in the MSc dissertation.

The project investigates whether passive seismic sensing can support:

- Traffic volume prediction
- Heavy-vehicle detection
- NO₂ prediction
- Traffic-related emissions estimation

using data collected on Oxford Road, Manchester.

## Main File

Seismic_Traffic_Pollution_Model.ipynb

## Key Results

- Traffic prediction (Gradient Boosting): R² = 0.807
- Heavy vehicle classification (Logistic Regression): Accuracy = 0.929
- NO₂ prediction (Random Forest): R² = 0.724
- Information retention:
  - Pearson = 96.9%
  - Spearman = 101.4%
